## 🌱 About the Project

**Fruit Store** is the starting point of a website that sells fresh fruits and a juice brand called **Koa** 🍹.

The pages in this repository are the **first building blocks** of that website. The project is still **under development** and not finished yet. It is also my way of practicing front-end development and JavaScript animations while building something real.

> 🚧 **Status:** Work in progress. New pages, features and the Koa juice section are still being built.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|:----------:|:--------|
| 🟧 **HTML** | Structure of the webpages |
| 🟦 **CSS** | Styling and layout |
| 🟨 **JavaScript** | Functionality and animations |
| 🟪 **XML / SVG** | Logo code used inside `animation.html` |
| 🎨 **Canva** | Used to design the SVG logo |

---

## 📂 Project Files

| File | Description |
|:-----|:------------|
| 🏪 `index.html` | Main store webpage |
| 🎨 `store1.css` | Website styling |
| ⚙️ `store1.js` | Website functionality |
| ✨ `animation.html` | Animation webpage, includes the XML and SVG code of my logo designed in Canva |
| 🎬 `animation.js` | Animation functionality (animates the logo) |
| 🖼️ `meloan.png` | Image asset used in the project |

---

## 🎨 Logo & Animation

The logo used in this project is an **SVG logo that I designed using Canva** 🖌️. I then took its **XML and SVG code** and added it directly inside `animation.html`, so the logo can be animated with JavaScript in `animation.js`.

## 🚀 How to Run

```bash
# 1. Clone the repository
git clone <your-repository-url>

# 2. Open the project folder
cd <project-folder>
```

3. Open **`index.html`** in your web browser.
4. Explore the website. 🍉

No installation or build tools needed. Just a browser!
